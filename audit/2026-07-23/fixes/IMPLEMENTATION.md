# Исправления по повторному UX-аудиту

Дата: 2026-07-23

## Что исправлено

- Готовность главной теперь требует только работоспособный Codex CLI и выполненный вход. Наличие старой папки сессий больше не блокирует первую задачу.
- Кнопки запуска требуют непустую инструкцию. Это действует и на главной, и в экспертном запуске.
- Результат или ошибка безопасного запуска показываются прямо на главной.
- Безопасная рабочая папка создаётся только для фактического запуска и удаляется при синхронной ошибке запуска, если в ней нет пользовательских файлов.
- Корень профиля пользователя и сам рабочий стол больше не считаются безопасной рабочей папкой.
- Начало настройки не помечает onboarding завершённым. Он завершается после успешной готовности Codex или после подтверждённого пропуска.
- Пропуск первого запуска получил отдельное подтверждение.
- Главная прокручивается по высоте и больше не теряет нижнюю кнопку в компактном окне.
- Простой экран установки заменён на три обязательных шага: установить Codex, войти и проверить готовность. Локальный AI вынесен в отдельный необязательный блок.
- DNS, OpenClaw, repair-команды и подробная диагностика остаются в экспертном режиме.
- В простой истории скрыты ID, JSONL, модель, источник, счётчики инструментов и транскрипт. Остались название, фрагмент разговора, дата и понятные действия.
- UUID-подобные заголовки заменяются читаемым описанием сессии.
- Экран обновлений различает обычную последнюю версию и локальную/тестовую сборку, которая новее опубликованного релиза.
- Основная оранжевая кнопка затемнена для достаточного контраста; placeholder стал темнее; выключенные кнопки теперь явно серые и читаемые.
- Добавлен заметный синий клавиатурный фокус.
- Расширена боковая навигация; «Расширенный запуск» больше не обрезается.
- Все 14 пользовательских кнопок на главной получили доступные имена. Поле задачи также имеет доступное имя и пояснение.

## Проверка

- Release build: 0 предупреждений, 0 ошибок.
- UI Automation: 14 из 14 пользовательских кнопок главной имеют имена; поле задачи также именовано.
- Кнопка безопасного запуска недоступна при пустой задаче и содержит объяснение причины.
- Нажатие «Начать настройку» не меняет сохранённый флаг завершения onboarding.
- При «Пока пропустить» появляется подтверждение; отмена сохраняет настройки без изменений.
- Клавиатурный фокус визуально подтверждён на кнопке примера.
- Временный код захвата скриншотов после проверки удалён.
- Пользовательские настройки возвращены в исходное состояние.

Реальный вход, установка инструментов и запуск Codex не выполнялись, чтобы не менять внешнее состояние компьютера без отдельной необходимости.
