# Проект: AIHelper

Общий контекст-файл для всех агентов (Codex, Claude Code). Источник правды — этот файл; CLAUDE.md рядом просто импортирует его.

## Что это
Windows WPF-приложение (C#/.NET, csproj `LaptopSessionViewer.csproj`, имя продукта — AIHelper) для работы с локальными сессиями Codex без терминала:
- просмотр/поиск сессий из `%USERPROFILE%\.codex\sessions`, избранное, заметки, удаление, продолжение сессии
- запуск новой сессии Codex с пресетами (модель, профиль, sandbox, approval, OSS)
- проверка/установка локального AI-стека, каталог плагинов и MCP
- управление DNS Windows (пресеты, DoH, откат)
- интерфейс EN/RU
GitHub: https://github.com/Havermeng/AIHelper (в релизах — self-contained инсталлятор Win10/11 x64)

## Структура
- Корень — WPF-приложение (MainWindow, StartupWindow, DnsPresetEditorWindow; Models/, Services/)
- `AIHelper.VisualStudioExtension/` — расширение для Visual Studio
- `installer/`, `publish/`, `dist/` — сборка и дистрибутив
- Данные приложения: `%USERPROFILE%\.codex\session_viewer_*.json` (favorites, notes, settings, opencode_links)

## История/заметки
- 2026-07-23: проект перенесён из `Desktop\LaptopSessionViewer` в эту папку (Claude). Раньше сессии Codex по нему велись из `C:\Windows\System32` — теперь рабочая папка проекта эта. Новые сессии Codex/Claude запускать отсюда.
